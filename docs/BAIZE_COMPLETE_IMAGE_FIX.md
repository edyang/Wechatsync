# 白泽文章同步助手：完整渠道修复版

版本：2.0.10.1。底包来自上游官网公开分发的 2.0.9 完整 ZIP，保留其全部29个渠道适配器，以及 WordPress / Typecho 等CMS入口。普通公开源码构建仍只有19个适配器；本包通过可审阅的独立补丁修复完整版，不需要访问上游私有子模块。

## 安装

1. 将 ZIP 解压到固定目录。
2. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），禁用之前的文章同步助手，开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择解压后的 `Wechatsync-Baize-Complete` 文件夹，确认名称及版本为本修复版。
4. 刷新已经打开的官网文章页；旧页面中的插件脚本不会自动换成新版。
5. 在同一浏览器正常登录要同步的平台。若使用MCP，填回既有WebSocket地址和浏览器桥接Token；无需重新部署MCP服务。

## 本次修复

- 官网页面使用真实H1与正文提取，不把浏览器标题中的公司SEO后缀带到平台。首页题图位于正文外，本包会将其纳入同步正文，保留原有正文图片，排除导航和页脚Logo。
- 相对图片路径转为完整地址；清理响应式 `srcset`、懒加载旧路径和样式中的图片引用。
- B站先将网站图片上传到B站，正文只保留B站图片CDN地址。WebP/AVIF按真实像素转换为PNG后上传，不以改后缀冒充JPEG。
- 图片转存失败或返回外站地址时明确报错，并停止保存新草稿；不再静默丢图或带着原外链继续保存。
- 微博同步旧文章时将过长标题限制到32个UTF-16单位，保留完整字符，不切断emoji；新文章由白泽内容任务直接生成32字以内标题。

同步仍保存为草稿，请在平台后台检查标题、图片、封面与排版后人工正式发布。此安装包未代替用户登录或执行真实账号发布；程序回归和完整渠道注册检查通过，不表示所有平台当天的接口和账号权限都已经验收。

## 包含的渠道

微信公众号、知乎、微博、小红书、头条、B站、抖音图文、豆瓣、X、掘金、CSDN、简书、思否、博客园、51CTO、开源中国、语雀、慕课手记、百家号、一点号、搜狐号、大鱼号、网易号、什么值得买、雪球、东方财富、人人都是产品经理、搜狐焦点，以及Markdown图片ZIP导出。视频上传不属于这些图文适配器的功能。

## 复现构建

在Fork的v2源码基础上安装锁文件依赖，运行 `node scripts/build-baize-complete.mjs`。脚本下载官方完整ZIP并验证固定SHA256，按JavaScript语法树定位补丁目标；目标或29个渠道集合不匹配时停止，避免无依据地替换新版程序。可用 `--input /absolute/path/official.zip` 指定已经下载的原包。

补丁源码、原包来源及SHA256分别放在 `PATCH_SOURCE` 与 `BUILD_REPORT.json`，完整项目源码和许可证保留在 `https://github.com/edyang/Wechatsync`。
